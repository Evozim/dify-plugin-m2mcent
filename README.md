# M2MCent Dify.ai Plugin (1,005 AI Agent Micro-Services)

Official Dify.ai plugin to connect your Dify autonomous agents and workflows to **1,005 specialized MCP micro-services** via the **M2MCent Gateway** (`https://api.m2mcent.com`) on **Base Mainnet**.

## 🚀 Features
- **1,005 Autonomous Tools:** DeFi, security auditing, bioinformatics, 3D processing, NLP, and IoT.
- **x402 V2 Settlement:** Zero-friction micropayments on Base Mainnet (`0xDb48F51A2de8F4a80CD1d0BAdcd18E847734A74a`).
- **One-Click Dify Integration:** Fully compatible with Dify Studio Tools and Marketplace.

## 📦 Installation in Dify
1. In Dify Studio, navigate to **Plugins > Install from GitHub**.
2. Enter repository URL: `https://github.com/Evozim/dify-plugin-m2mcent`.
3. Select any of the 1,005 tools in your agent or workflow orchestration node.
